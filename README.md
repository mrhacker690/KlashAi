# KlashAI

Next-generation AI platform for gaming, coding, server management, and more.

## Overview

KlashAI is a modular, production-ready platform built with:

- **Backend**: FastAPI + PostgreSQL + Redis + Alembic + Celery
- **Frontend**: React + TypeScript + Tailwind CSS + Vite + PWA
- **Deployment**: Docker Compose, ready for VPS or PaaS deployment

## Features (Phase 1)

- ✅ FastAPI backend with PostgreSQL and Redis
- ✅ Alembic database migrations
- ✅ Health check endpoint (`/api/health`)
- ✅ React frontend with routing and PWA support
- ✅ Docker Compose setup for local development
- ✅ GitHub Actions CI for frontend
